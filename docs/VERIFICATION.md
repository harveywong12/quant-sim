## 复现

```bash
python tools/check_publication.py
python tools/run_offline_tests.py
node --check qsim/services/web/static/app.js
python -m pip wheel --no-deps --no-build-isolation --no-index . -w dist
```

打包环境需要事先安装 `setuptools` 和 `wheel`。应用运行环境与打包环境分开；测试安装使用 README 指定的锁定依赖。源码部署仍需保留项目根目录的配置与数据目录，wheel 不是一键生成完整行情库的安装包。

原始测试日志和 XML 可能带有本机解释器与临时目录信息，所以只保存于本地私有交付目录，不上传 GitHub。公开文档只记录可复核的技术统计。
